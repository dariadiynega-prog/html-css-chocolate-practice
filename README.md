# Simply Chocolate

## План заняття

- Створення структури HTML
- Робота із семантичними тегами
- Додавання зображень із макета

## Технічне завдання

- HTML-файл називається index.html
- У корені проєкту є папка images
- Назви файлів без кирилиці та пробілів
- Код відформатований Prettier
- Текст і зображення взяті з макета Simply Chocolate
